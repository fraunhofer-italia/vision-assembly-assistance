# Repository contents

This repository contains the assembly/disassembly guidance UI, offline pipeline, calibration tools, statistical analysis, detector/classifier training utilities and a camera-free example.

Datasets, recordings and weights are on [Hugging Face](artifacts.md). The repositories are publicly accessible.

Live capture uses OAK-D/DepthAI and the configured calibration and model files. The statistical workflow uses the released study inputs. See [input formats](data_contract.md) and [verification](verification.md).

The code uses MIT; dependencies and models retain their [respective licenses](licensing.md).
